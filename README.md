# London Airbnb Listings

This repository explores the spatial distribution of Airbnb prices across London neighbourhoods.

## Data

The repository uses publicly available Airbnb listings data from [Inside Airbnb](https://insideairbnb.com/get-the-data/).

The dataset (`listings.csv`) contains information on Airbnb listings in London, including their locations, prices, room types, and other characteristics.
